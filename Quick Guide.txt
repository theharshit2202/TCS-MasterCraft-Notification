MasterCraft Notification System - User Guide
=========================================

This application helps you monitor defects in MasterCraft ALM and notifies you when new defects are found.

Quick Start
----------
1. Make sure you have Python installed on your computer
2. Install the required packages by running:
   pip install -r requirements.txt
3. Create a file named 'mc.env' in the same folder with your settings
4. Run the program:
   python MasterCraft_Notification.py

Important Notes
-------------
1. Keep your Edge browser updated
2. Make sure you have a stable internet connection
3. Don't close the console window while the program is running
4. The program will create a log file (selenium_errors.log) to track its operation

Using the Program
---------------
1. The program will automatically check for new defects
2. When new defects are found, you'll see a notification
3. You can click the 'Stop' button in the notification to pause monitoring for 30 minutes
4. To resume monitoring before 30 minutes:
   - Type 'resume' in the console window
   - Or wait for automatic resume after 30 minutes

Configuration (mc.env file)
-------------------------
Create a file named 'mc.env' with these settings:

Required Settings:
BASE_URL=your_mastercraft_url
FALLBACK_URL=your_fallback_url
CURRENT_USER=your_username
TARGET_STATUSES=open,assigned
MASTERCRAFT_LOGIN_ID=your_login_id
MASTERCRAFT_PASSWORD=your_password

Optional Settings (in seconds):
CHECK_INTERVAL_WITH_DEFECTS=180    # Check every 3 minutes when defects are found
CHECK_INTERVAL_NO_DEFECTS=60       # Check every 1 minute when no defects are found
PAUSE_DURATION=1800               # Pause duration (30 minutes)

Troubleshooting
-------------
1. If notifications don't appear:
   - Check Windows notification settings
   - Make sure you're using Windows 10 or later

2. If the program can't connect:
   - Check your internet connection
   - Verify your URLs in mc.env
   - Make sure your login credentials are correct

3. If the program crashes:
   - Check selenium_errors.log for details
   - Make sure Edge WebDriver is installed
   - Verify all required packages are installed

4. Common Issues:
   - "WebDriver not found": Install Edge WebDriver
   - "Module not found": Run pip install -r requirements.txt
   - "Invalid credentials": Check your mc.env file

Support
-------
If you encounter any issues:
1. Check the log file (selenium_errors.log)
2. Verify your configuration in mc.env
3. Make sure all requirements are installed
4. Contact your system administrator

Remember
-------
- Keep your credentials secure
- Don't share your mc.env file
- Regular program updates are recommended
- Monitor the log file for any issues
